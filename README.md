# HTML Audio Element

## Explanation

This project demonstrates how to embed an audio file into a webpage using the HTML5 `<audio>` element.

## Problem Statement

Create an HTML webpage that allows users to play an audio file using built-in browser controls.

## Features

* Audio playback
* Play and pause controls
* Volume control
* Browser-supported audio player
* Simple HTML5 implementation

## How It Works

The `<audio>` element is used to embed audio content in an HTML webpage.

The `controls` attribute displays the browser's built-in audio controls.

The `<source>` element specifies the audio file and its format.

## Technologies Used

* HTML5

## Program Flow

1. Open the webpage.
2. The audio player is displayed.
3. Click the Play button.
4. Listen to the audio.
5. Use the controls to pause or adjust the volume.

## Sample Input

Audio file: `music.mp3`

## Sample Output

An audio player is displayed on the webpage with playback controls.

## Key Learning

* `<audio>` element
* `<source>` element
* `controls` attribute
* Embedding multimedia in HTML
